# NEWSROOM AI – TRANG DUYỆT BÀI

## 1. Thông tin đề tài
- **Tên đề tài:** Newsroom AI – Hệ thống quản lý tin tức
- **Tên trang:** Duyệt bài
- **Môn học:** Phát triển ứng dụng Web cơ bản – CSE122

## 2. Mục đích
Xây dựng trang web giúp phóng viên và biên tập viên quản lý, tìm kiếm, duyệt và cập nhật trạng thái bài viết.

## 3. Chức năng chính
- Hiển thị danh sách bài viết.
- Tìm kiếm và lọc bài viết.
- Chuyển đổi Tab và phân trang.
- Xem chi tiết và cập nhật trạng thái.
- Thêm bài viết mới.
- Chuyển đổi giao diện sáng/tối.
- Hỗ trợ Responsive.

## 4. Công nghệ sử dụng
- **HTML5:** Xây dựng cấu trúc trang web.
- **CSS3:** Thiết kế giao diện và Responsive.
- **JavaScript:** Xử lý dữ liệu và các chức năng tương tác.
